## 2. 程序入口

使用 `WinMain()` 入口函数

```cpp
int WINAPI WinMain(HINSTANCE, HINSTANCE, LPSTR, int) {
    return 0;
}
```
- `HINSTANCE` 等参数是固定入口写法

### 3. 初始化

使用 `KamataEngine::Initialize()` 启动引擎。  
引擎内部会自动创建窗口，并完成各种初始化操作。

```cpp
KamataEngine::Initialize(L"GC2C_02_ゴ_チュウ");
```

- `L""`：引号里用于设置窗口标题名字

---

### 4. 主循环 

```cpp
while (true) {

    // 更新处理

    // 引擎自更新 + 自检退出
    if (KamataEngine::Update()) {
        break;
    }
}
```
>#### 自检退出函数的解释
>`KamataEngine::Update()`是引擎每帧执行的更新函数
>
>除了更新引擎状态外，还会自动检测窗口是否被关闭（例如点击右上角 × 或 Alt + >F4）；当检测到窗口关闭时会返回 `true`，从而通过 `break` 退出主循环
>    
>当然开发者也可以自己额外添加例如 ESC 等其它退出条件。
>
>因为我们以前都是手动添加break, 这里解释一下

---

### 5. 释放

使用 `Finalize()` 结束引擎，并释放窗口和各种资源。

```cpp
KamataEngine::Finalize();
```
