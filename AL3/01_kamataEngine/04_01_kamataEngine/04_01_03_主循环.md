## 1. DirectXCommon

在进入主循环之前，因为 KAMATA ENGINE 内部实际上仍然使用 DirectX12 进行绘图。  所以需要先获取：`DirectXCommon` 这个负责管理 DirectX 绘图处理的类。

初始化：

```cpp
DirectXCommon* dxCommon =
    DirectXCommon::GetInstance();
```

- 不同于：`Enemy* enemy1 = new Enemy();`创建新对象
因为 `DirectXCommon` 对象已经在引擎内部存在，所以直接使用`GetInstance()`取得, 并让 `dxCommon` 指针指向它即可

- 通过这个指针对象即可调用DirectX12的绘画函数

```cpp
    dxCommon->PreDraw() //开始绘图;
    dxCommon->PostDraw()//结束绘图;
```

## 2. 主循环:画面绘制

DirectX12的绘图代码需要写在`PreDraw()` 和 `PostDraw()`之间

```cpp
while (true) {
    if (KamataEngine::Update()) {
        break;
    }
    dxCommon->PreDraw();
    // 在这里写绘图代码
    dxCommon->PostDraw();
}
```

## 3. 创建类实例和调用

```cpp
int WINAPI WinMain(HINSTANCE, HINSTANCE, LPSTR, int)
{
    KamataEngine::Initialize();

    DirectXCommon* dxCommon =
        DirectXCommon::GetInstance();

    // 创建实例
    GameScene* gameScene =
        new GameScene();

    // 初始化实例
    gameScene->Initialize();

    while (true) {
        if (KamataEngine::Update()) {
            break;
        }

        //调用实例
        gameScene->Update();

        dxCommon->PreDraw();

        gameScene->Draw();

        dxCommon->PostDraw();
    }

    // 删除实例
    delete gameScene;
    gameScene = nullptr;


    KamataEngine::Finalize();
    return 0;
}
```
