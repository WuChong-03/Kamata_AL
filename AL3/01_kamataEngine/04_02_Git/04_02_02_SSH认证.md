## 1. SSH认证是什么

SSH认证可以理解成：

**一把用于 GitHub 仓库操作的设备锁**

SSH 会生成：

- **公開鍵** : 上传到 GitHub 的锁
- **秘密鍵** : 保存在自己电脑里的钥匙

---

## 2. 普通密保 与 SSH 的区别

- 普通密保 = **账号认证**
- SSH = **设备认证**

---

## 3. 什么是 collaborator

协作者，在 GitHub 网站上通过邀请添加。

### public仓库

- 访问权 : 开放
- Push等管理操作 : 需要 collaborator

### private仓库

- 访问权 : 需要 collaborator
- Push等管理操作 : 需要 collaborator
- 通常更常搭配 SSH 认证，每个人上传并管理自己的 SSH key，各自进行设备验证与保护

---

## 4. 如何创建和使用 SSH

- 使用 Fork、Git Bash（ssh-keygen）等工具创建本地 SSH key

- 本地会生成：
  - 秘密鍵
  - 公開鍵

- 将 Public Key 复制到 GitHub：

```text
Settings
↓
SSH and GPG keys
↓
New SSH key
```

- GitHub 会保存你的 Public Key，用于之后的设备认证

- 一般：
  - private仓库 更常使用 SSH
  - public仓库 可以不用 SSH
