```text
↓
之后通过 Sprite 指针操作图片
```

## 1. 读取资源并存进句柄

创建句柄，使用 `Load()` 读取图片，并把得到的图片编号存进句柄。

```cpp
uint32_t textureHandle = 0;
textureHandle = TextureManager::Load("uvChecker.png");
```

- `uint32_t`

	`uint32_t` 是 C++11 之后常用的固定大小整数类型, 表示 32bit 的无符号整数。  
	游戏和通信处理中经常重视数据大小，一般不会模糊地使用 `int` 或 `unsigned int`。  
	`= 0`也可以用 `0u` 表示无符号整数的 0，和 `uint32_t` 类型更匹配。
	
- `textureHandle`
  : `uint32_t` 类型的变量，用于保存读取图片后得到的编号，之后会使用这个编号指定显示哪张图片

- `TextureManager::Load()`
  : 属于 `TextureManager` 的 `Load` 函数，用于把图片文件读取进程序中，并返回对应图片的编号

## 2. 生成 Sprite 实例

创建 Sprite 指针，再用 `Create()` 生成 Sprite 对象。

```cpp
Sprite* sprite = nullptr;
sprite = Sprite::Create(textureHandle, {100, 50});
```

- `Sprite * sprite`
  : Sprite 类型的指针变量，用于之后指向并操作生成出来的 Sprite 对象

- `nullptr`
  : 表示目前还没有指向任何 Sprite 对象

- `Sprite::Create()`
  : 属于 `Sprite` 的生成函数，用于创建 Sprite 对象

- `textureHandle`
  : 指定要使用哪张图片

- `{100, 50}`
  : Sprite 初始坐标

---

## 3. 绘图

和基础框架里的 `DirectXCommon` 一样,   
 `Sprite` 也有自己的 `PreDraw()` 与 `PostDraw()`。

- `dxCommon`
  : 控制整个画面的绘图开始与结束,位于所有绘图处理的最外层

- `Sprite`
  : 控制 Sprite 图片系统自己的绘图开始与结束

```cpp
dxCommon->PreDraw();

Sprite::PreDraw();
sprite->Draw();
Sprite::PostDraw();

dxCommon->PostDraw();
```
---

## 4. 移动

Sprite 对象自身拥有坐标属性参数。  
修改其坐标时，需要使用对应的取值器与设值器。

```cpp
Vector2 position = sprite->GetPosition();

position.x += 2.0f;
position.y += 1.0f;

sprite->SetPosition(position);
```

---

## 5. 释放

```cpp
delete sprite;
sprite = nullptr;
```

## 完整演示代码

```cpp
#include <Windows.h>
#include "KamataEngine.h"

using namespace KamataEngine;

int WINAPI WinMain(_In_ HINSTANCE, _In_opt_ HINSTANCE, _In_ LPSTR, _In_ int) {

	// 初期化区
	Initialize(L"GC2C_02_ゴ_チュウ");

	DirectXCommon* dxCommon = DirectXCommon::GetInstance();

	// 读取并创建句柄存图片编号
	uint32_t textureHandle = 0;
	textureHandle = TextureManager::Load("uvChecker.png");

	// 创建实例并填写初始化参数
	Sprite* sprite1 = nullptr;
	Sprite* sprite2 = nullptr;
	sprite1 = Sprite::Create(textureHandle, {100, 50});
	sprite2 = Sprite::Create(textureHandle, {300, 200});

	// 主循环
	while (true) {

		if (Update()) {
			break;
		}

		// 移动
		Vector2 position1 = sprite1->GetPosition();
		position1.x += 2.0f;
		sprite1->SetPosition(position1);

		// DirectX 绘图开始
		dxCommon->PreDraw();

		// Sprite 绘图开始
		Sprite::PreDraw();

		sprite1->Draw();
		sprite2->Draw();

		// Sprite 绘图结束
		Sprite::PostDraw();

		// DirectX 绘图结束
		dxCommon->PostDraw();
	}

	// 释放
	delete sprite1;
	sprite1 = nullptr;

	delete sprite2;
	sprite2 = nullptr;

	// 引擎结束
	Finalize();

	return 0;
}
```
