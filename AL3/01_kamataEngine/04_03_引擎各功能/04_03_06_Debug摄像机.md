# Debug摄像机

```text
创建 DebugCamera
↓
每帧更新 DebugCamera
↓
把 DebugCamera 的 Camera 信息交给 Model
↓
用鼠标自由观察 3D 世界
```

DebugCamera 是开发时用的调试摄像机。  
可以自由移动、旋转、缩放视角，方便确认：

- 模型位置
- 旋转方向
- 碰撞
- 地图结构
- 3D 空间关系

KAMATA ENGINE 已经提前做好了 DebugCamera。

## 1. DebugCamera 是什么

DebugCamera 是 KAMATA ENGINE 内置的调试摄像机。

开发时可以用鼠标自由观察 3D 空间。

操作方式：

- 左键拖动
  : 围绕注视点旋转

- 鼠标滚轮
  : 接近 / 远离

- 中键拖动
  : 平行移动

---

## 2. 创建 DebugCamera

先在 `.h` 中准备 DebugCamera 指针。

```cpp
DebugCamera* debugCamera_ = nullptr;
```

之后使用 `new` 创建 DebugCamera。

```cpp
debugCamera_ = new DebugCamera(1280, 720);
```

- `DebugCamera`
  : 调试摄像机类

- `1280`
  : 画面横宽

- `720`
  : 画面纵宽

- `new`
  : 在内存中创建对象

---

## 3. 更新 DebugCamera

DebugCamera 需要每帧更新。

```cpp
debugCamera_->Update();
```

这样鼠标操作才会生效。

通常写在 `Update()` 内。

---

## 4. 使用 DebugCamera 绘图

绘图时，把 DebugCamera 的 Camera 信息交给 Model。

```cpp
model->Draw(
	worldTransform,
	debugCamera_->GetCamera(),
	textureHandle
);
```

- `GetCamera()`
  : 取得 DebugCamera 内部真正使用的 Camera

DebugCamera 本身主要负责：

- 鼠标操作
- 摄像机移动
- 视图计算

真正绘图时，Model 需要的是 Camera 信息。

---

## 5. 释放 DebugCamera

使用 `new` 创建后，需要 `delete` 释放。

```cpp
delete debugCamera_;
debugCamera_ = nullptr;
```

## 完整演示代码

```cpp
#include <Windows.h>
#include "KamataEngine.h"

using namespace KamataEngine;

int WINAPI WinMain(
	_In_ HINSTANCE,
	_In_opt_ HINSTANCE,
	_In_ LPSTR,
	_In_ int) {

	// 引擎初始化
	Initialize(L"GC2C_02_ゴ_チュウ");

	DirectXCommon* dxCommon =
		DirectXCommon::GetInstance();

	// 读取贴图
	uint32_t textureHandle = 0;
	textureHandle =
		TextureManager::Load("mario.jpg");

	// 创建 Model
	Model* model = nullptr;
	model = Model::Create();

	// WorldTransform
	WorldTransform worldTransform;
	worldTransform.Initialize();

	// 创建 DebugCamera
	DebugCamera* debugCamera = nullptr;
	debugCamera = new DebugCamera(1280, 720);

	// 主循环
	while (true) {

		// 结束判定
		if (Update()) {
			break;
		}

		// 更新 DebugCamera
		debugCamera->Update();

		// 模型旋转
		worldTransform.rotation_.y += 0.02f;

		// DirectX 绘图开始
		dxCommon->PreDraw();

		// Model 绘图开始
		Model::PreDraw();

		// 使用 DebugCamera 绘图
		model->Draw(
			worldTransform,
			debugCamera->GetCamera(),
			textureHandle
		);

		// Model 绘图结束
		Model::PostDraw();

		// DirectX 绘图结束
		dxCommon->PostDraw();
	}

	// 释放 DebugCamera
	delete debugCamera;
	debugCamera = nullptr;

	// 释放 Model
	delete model;
	model = nullptr;

	// 引擎结束
	Finalize();

	return 0;
}
```
