# 坐标轴方向显示（AxisIndicator）

```text
开启 AxisIndicator
↓
指定要跟随的 Camera
↓
在 main.cpp 中调用 Draw()
↓
画面右上角显示 XYZ 坐标轴
```

---

## 1. AxisIndicator 是什么

当 3D 场景里的物体还很少时，

有时会分不清：

- 是模型在动
- 还是摄像机在动

所以很多 3DCG 工具（例如 Blender）都会显示一个：

```text
XYZ 坐标轴方向显示
```

KAMATA ENGINE 也准备了这个功能。

通常显示在：

```text
画面右上角
```

---

## 2. 坐标轴颜色

默认颜色：

| 轴 | 颜色 |
|---|---|
| X轴 | 红色 |
| Y轴 | 绿色 |
| Z轴 | 蓝色 |

这是 3D 软件中非常常见的规则。

---

## 3. 开启 AxisIndicator

在 `Initialize()` 中开启。

```cpp
AxisIndicator::GetInstance()->SetVisible(true);
```

---

## 4. 指定要跟随的 Camera

AxisIndicator 必须知道：

```text
现在是谁在观察 3D 世界
```

所以需要把 Camera 交给它。

```cpp
AxisIndicator::GetInstance()->
	SetTargetCamera(
		&debugCamera_->GetCamera()
	);
```

这里通常会使用：

```cpp
DebugCamera
```

这样坐标轴方向会跟着 DebugCamera 一起变化。

---

## 5. 在 main.cpp 中绘图

AxisIndicator 不是自动绘图。

需要在主循环中调用：

```cpp
AxisIndicator::GetInstance()->Draw();
```

---

## 6. Draw 的位置非常重要

必须写在：

```cpp
gameScene->Draw();
之后
```

因为 AxisIndicator 会修改：

- 绘图区域
- Viewport
- 部分绘图状态

如果顺序错了，

后面的东西可能会：

```text
被画到右上角
```

---

## 正确顺序

```cpp
dxCommon->PreDraw();

gameScene->Draw();

// AxisIndicator
AxisIndicator::GetInstance()->Draw();

// ImGui
imguiManager->Draw();

dxCommon->PostDraw();
```

---

## 7. 运行效果

画面右上角会出现：

```text
XYZ 坐标轴
```

并且：

- 摄像机旋转
  → 坐标轴跟着旋转

- 摄像机平移
  → 坐标轴不会移动

因为它表示的是：

```text
方向
```

不是位置。

# 完整演示代码

## GameScene.h

```cpp
#pragma once

#include "KamataEngine.h"

using namespace KamataEngine;

class GameScene {
public:

	// 初始化
	void Initialize();

	// 更新
	void Update();

	// 绘图
	void Draw();

private:

	// Model
	Model* model_ = nullptr;

	// WorldTransform
	WorldTransform worldTransform_;

	// DebugCamera
	DebugCamera* debugCamera_ = nullptr;

	// 贴图
	uint32_t textureHandle_ = 0;
};
```

---

## GameScene.cpp

```cpp
#include "GameScene.h"

void GameScene::Initialize() {

	// 读取贴图
	textureHandle_ =
		TextureManager::Load("mario.jpg");

	// 创建 Model
	model_ = Model::Create();

	// 初始化 WorldTransform
	worldTransform_.Initialize();

	// 创建 DebugCamera
	debugCamera_ =
		new DebugCamera(1280, 720);

	// 开启 AxisIndicator
	AxisIndicator::GetInstance()->
		SetVisible(true);

	// 指定 Camera
	AxisIndicator::GetInstance()->
		SetTargetCamera(
			&debugCamera_->GetCamera()
		);
}

void GameScene::Update() {

	// 更新 DebugCamera
	debugCamera_->Update();

	// 模型旋转
	worldTransform_.rotation_.y += 0.02f;
}

void GameScene::Draw() {

	// 绘制 Model
	model_->Draw(
		worldTransform_,
		debugCamera_->GetCamera(),
		textureHandle_
	);
}
```

---

## main.cpp

```cpp
#include <Windows.h>
#include "KamataEngine.h"
#include "GameScene.h"

using namespace KamataEngine;

int WINAPI WinMain(
	_In_ HINSTANCE,
	_In_opt_ HINSTANCE,
	_In_ LPSTR,
	_In_ int) {

	// 引擎初始化
	Initialize(L"GC2C_02_ゴ_チュウ");

	DirectXCommon* dxCommon =
		DirectXCommon::GetInstance();

	// 创建 GameScene
	GameScene* gameScene =
		new GameScene();

	gameScene->Initialize();

	// ImGui
	ImGuiManager* imguiManager =
		ImGuiManager::GetInstance();

	// 主循环
	while (true) {

		// 结束判定
		if (Update()) {
			break;
		}

		// ImGui Begin
		imguiManager->Begin();

		// 更新
		gameScene->Update();

		// ImGui End
		imguiManager->End();

		// 开始绘图
		dxCommon->PreDraw();

		// 3D 绘图开始
		Model::PreDraw();

		// 绘图
		gameScene->Draw();

		// 3D 绘图结束
		Model::PostDraw();

		// AxisIndicator
		AxisIndicator::GetInstance()->Draw();

		// ImGui 绘图
		imguiManager->Draw();

		// 绘图结束
		dxCommon->PostDraw();
	}

	// 删除 GameScene
	delete gameScene;

	// 引擎结束
	Finalize();

	return 0;
}
```
