## 1. 获取实例

```cpp
ImGuiManager* imguiManager =
	ImGuiManager::GetInstance();
```

获取引擎内部已经存在的 `ImGuiManager` 对象。

---

## 2. 基础框架 Begin / End / Draw

```cpp
	imguiManager->Begin();

	// ImGui 命令
	// ImGui 命令
	// ImGui 命令

	imguiManager->End();
```

```cpp
	// dxCommon->PreDraw();

	imguiManager->Draw();

	// dxCommon->PostDraw();
```

- `Begin()` 和 `End()` 之间用于编写 ImGui 命令
- `Draw()` 放在整体 `dxCommon` 绘制处理中
- ImGui 会自动生成 GUI 窗口

## 3. 各类 GUI 命令

各类 GUI 命令都需要写在 `Begin()` 和 `End()` 中。

### 3.1 文本

```cpp
ImGui::Text("HP = %d", hp);
```

---

### 3.2 修改变量

我们可以通过 GUI 直接修改变量，常用工具有两种：输入框和滑动条。

```cpp
ImGui::InputFloat3(
	"InputFloat3",	// 此工具命名
	inputFloat3);	// 控制的变量地址

ImGui::SliderFloat3(
	"SliderFloat3", // 此工具命名
	inputFloat3,	// 控制的变量地址
	0.0f,			// 最小值
	1.0f);			// 最大值
```

- 注意点1：`Float` 版的 `Input` 和 `Slider` 只能控制 `float` 变量；如果是 `int` 变量，需要使用 `InputInt` / `SliderInt`

- 注意点2：变量参数需要传地址。  
  如果是普通变量，需要使用 `&` 取地址，例如 `&a`。  
  如果本身就是对应类型的指针变量，例如 `float* a`，则可以直接传入。  
  对象成员变量通常使用 `&enemy1->posX`

- 注意点3：关于格式  
  如果使用 `ImGui::InputFloat()`，一次命令只会生成 1 个框。  
  如果使用 `ImGui::InputFloat3()`，一次命令会生成 1 行 3 个框。  
  后面的数字表示：这个 GUI 组件一次控制几个变量。

- 注意点4：多个变量通常需要使用数组，并且数组元素数量要和函数名后面的数字对应。  
  例如 `InputFloat3()` 需要可以连续访问的 3 个 `float`。

## 4. ReleaseBuild 注意点

因为 ImGui 属于开发调试功能，真正发布的 Release 版本通常不会显示。

所以一般会使用：

```cpp
#ifdef _DEBUG

// ImGui 相关代码

#endif
```

让相关代码只在 Debug 模式下编译，Release 模式会自动忽略。
