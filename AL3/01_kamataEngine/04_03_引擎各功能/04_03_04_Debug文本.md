# 1. 获取 ImGuiManager 实例

KAMATA ENGINE 使用外部库 `ImGui` 来显示 Debug 文本。

首先需要获取 `ImGuiManager` 实例。

```cpp
ImGuiManager* imguiManager =
	ImGuiManager::GetInstance();
```

- `ImGuiManager`
  : 管理 ImGui Debug 系统

- `GetInstance()`
  : 获取引擎内部已经存在的 ImGuiManager 对象

---

# 2. 每帧处理

ImGui 每一帧都需要：

```text
Begin()
↓
写 ImGui 命令
↓
End()
↓
Draw()
```

主循环：

```cpp
while (true) {

	if (Update()) {
		break;
	}

	// ImGui 开始
	imguiManager->Begin();

	// 游戏更新
	gameScene->Update();

	// ImGui 结束
	imguiManager->End();

	// DirectX 绘图开始
	dxCommon->PreDraw();

	// 游戏绘图
	gameScene->Draw();

	// ImGui 绘图
	imguiManager->Draw();

	// DirectX 绘图结束
	dxCommon->PostDraw();
}
```

---

## 为什么 Draw() 要放这里

ImGui 的文字并不是立刻显示。

实际上：

```text
Begin() ～ End()
```

之间只是：

- 暂存 ImGui 命令

真正绘制是在：

```cpp
imguiManager->Draw();
```

时才生成 DirectX12 绘图命令。

因此：

```cpp
dxCommon->PreDraw();
～
dxCommon->PostDraw();
```

之间必须调用：

```cpp
imguiManager->Draw();
```

# 3. 显示 Debug 文本

在 `Update()` 中调用：

```cpp
ImGui::Text(
	"Kamata Tarou %d.%d.%d",
	2050,
	12,
	31);
```

---

## Text 的特点

类似 `printf`

```cpp
%d
```

可以把变量值插进去。

例如：

```cpp
int hp = 100;

ImGui::Text("HP = %d", hp);
```

显示结果：

```text
HP = 100
```

---

## 注意

ImGui 默认主要支持：

- 英文
- 数字
- 部分 ASCII 符号

日文、中文通常会乱码。

所以 Debug 文本一般使用英文。

# 4. 创建窗口

使用：

```cpp
ImGui::Begin();
～
ImGui::End();
```

可以创建 Debug 窗口。

```cpp
ImGui::Begin("Debug1");

ImGui::Text("Hello");

ImGui::End();
```

---

## Begin 的参数

```cpp
"Debug1"
```

是窗口标题。

---

## 效果

```text
┌────────────┐
│ Debug1     │
│ Hello      │
└────────────┘
```

# 5. InputFloat 与 Slider

ImGui 可以直接修改变量。

---

## 准备变量

```cpp
float inputFloat3[3] = {0, 0, 0};
```

---

## 输入框

```cpp
ImGui::InputFloat3(
	"InputFloat3",
	inputFloat3);
```

---

## Slider

```cpp
ImGui::SliderFloat3(
	"SliderFloat3",
	inputFloat3,
	0.0f,
	1.0f);
```

---

## Slider 参数

```cpp
SliderFloat3(
	名字,
	变量,
	最小值,
	最大值)
```

---

## 用途

这种功能非常适合：

- 调整坐标
- 调整颜色
- 调整速度
- 调整光照参数
- 调试碰撞范围

因为不用重新编译。

# 7. ReleaseBuild 注意点

ImGui 属于：

```text
开发调试功能
```

真正发布游戏时通常不会显示。

---

## 常见写法

```cpp
#ifdef _DEBUG

ImGui::Text("HP = %d", hp);

#endif
```

---

## 意思

```text
只有 Debug 模式才编译
```

Release 模式会自动忽略。

# 完整演示代码

```cpp
#include <Windows.h>
#include "KamataEngine.h"
#include "2d/ImGuiManager.h"

using namespace KamataEngine;

int WINAPI WinMain(
	_In_ HINSTANCE,
	_In_opt_ HINSTANCE,
	_In_ LPSTR,
	_In_ int) {

	// 引擎初始化
	Initialize(L"GC2C_02_ゴ_チュウ");

	DirectXCommon* dxCommon =
		DirectXCommon::GetInstance();

	// ImGuiManager 实例获取
	ImGuiManager* imguiManager =
		ImGuiManager::GetInstance();

	// ImGui 用变量
	float inputFloat3[3] = {0, 0, 0};

	// 主循环
	while (true) {

		if (Update()) {
			break;
		}

		// ImGui 开始
		imguiManager->Begin();

#ifdef _DEBUG

		// 创建窗口
		ImGui::Begin("Debug");

		// Debug 文本
		ImGui::Text(
			"Kamata Tarou %d.%d.%d",
			2050,
			12,
			31);

		// 输入框
		ImGui::InputFloat3(
			"InputFloat3",
			inputFloat3);

		// Slider
		ImGui::SliderFloat3(
			"SliderFloat3",
			inputFloat3,
			0.0f,
			1.0f);

		// DemoWindow
		ImGui::ShowDemoWindow();

		ImGui::End();

#endif

		// ImGui 结束
		imguiManager->End();

		// DirectX 绘图开始
		dxCommon->PreDraw();

		// ImGui 绘图
		imguiManager->Draw();

		// DirectX 绘图结束
		dxCommon->PostDraw();
	}

	// 引擎结束
	Finalize();

	return 0;
}
```
