# Model

模型就是 = **3D本体 + 2D贴图**  
处理模型时,一般有以下步骤
```text
读取贴图并创建句柄存编号（textureHandle）
↓
把编号交给 Model 指针对象(到此处和读图片一致)
↓
Model 还需要 WorldTransform 与 Camera
↓
之后通过 Model 指针操作3D模型
```

素材放置 : `DirectXGame/Resources`

## 1. 读取贴图并存进句柄

创建句柄，使用 `Load()` 读取贴图，并把得到的贴图编号存进句柄。

```cpp
uint32_t textureHandle = 0;
textureHandle = TextureManager::Load("mario.jpg");
```

- `textureHandle`
  : 保存读取贴图后得到的图片编号（Handle）

- `TextureManager::Load()`
  : 读取图片并返回对应编号

---

## 2. 生成 Model 实例

创建 Model 指针，再用 `Create()` 生成 Model 对象。

```cpp
Model* model = nullptr;
model = Model::Create();
```

- `Model* model`
  : Model 类型的指针变量，用于之后操作生成出来的 3D Model 对象；
  
  和 Sprite 实例创建时就指定贴图不同，Model 实例创建时通常不直接指定贴图，因为贴图一般在 `Draw()` 时再交给 Model 使用

- `nullptr`
  : 表示目前还没有指向任何对象

- `Model::Create()`
  : 属于 `Model` 的生成函数，用于创建 3D Model 对象

---
## 3. 关于 WorldTransform 与 Camera

生成 Model 实例之后，如果想要正常绘制模型，还需要两个重要参数：

- 坐标与变换：`WorldTransform`
- 参照摄像机：`Camera`

`WorldTransform` 和 `Camera` 都是 KAMATA ENGINE 提供的类。  
因为已经包含在 `KamataEngine.h` 中，所以可以不单独 `include`，直接声明并初始化使用。

在本节中，我们先在 `main` 中创建并初始化它们

```cpp
WorldTransform worldTransform;
Camera camera;

worldTransform.Initialize();
camera.Initialize();
```

然后作为参数传给 `model->Draw()`绘制时使用：

```cpp
model->Draw(worldTransform, camera, textureHandle);
```

不过在实际开发中，`Camera` 往往会和 `Scene` 的生命周期绑定。  
也就是说，`Camera / DebugCamera` 通常会放在 `GameScene` 中声明、创建和更新，再由 `GameScene` 统一管理。

这一部分会在 `04_03_06_Debug摄像机` 中继续学习。

本节为了方便学习，先在 `main` 中一起处理。

## 4. 绘图

和 `Sprite` 与 `DirectXCommon` 一样，  
`Model` 也有自己的 `PreDraw()` 与 `PostDraw()`。

- `dxCommon`
  : 控制整个画面的绘图开始与结束, 位于所有绘图处理的最外层

- `Sprite`
  : 控制 Sprite 图片系统自己的绘图开始与结束

- `Model`
  : 控制 3D Model 系统自己的绘图开始与结束

```cpp
dxCommon->PreDraw();

Model::PreDraw();

model->Draw(worldTransform, camera, textureHandle);

Model::PostDraw();

dxCommon->PostDraw();
```

---

## 5. 释放

```cpp
delete model;
model = nullptr;
```

## 完整演示代码

```cpp
#include <Windows.h>
#include "KamataEngine.h"

using namespace KamataEngine;

int WINAPI WinMain(_In_ HINSTANCE, _In_opt_ HINSTANCE, _In_ LPSTR, _In_ int) {

	// 初期化区
	Initialize(L"GC2C_02_ゴ_チュウ");

	DirectXCommon* dxCommon = DirectXCommon::GetInstance();

	// 读取贴图并创建句柄
	uint32_t textureHandle = 0;
	textureHandle = TextureManager::Load("mario.jpg");

	// 创建 Model 实例
	Model* model = nullptr;
	model = Model::Create();

	// WorldTransform 与 Camera 的实例创建, 初始化
	WorldTransform worldTransform;
	worldTransform.Initialize();
	Camera camera;
	camera.Initialize();

	// 主循环
	while (true) {

		if (Update()) {
			break;
		}

		dxCommon->PreDraw();

		// Model 绘图开始
		Model::PreDraw();
		// Model 绘图
		model->Draw(worldTransform, camera, textureHandle);
		// Model 绘图结束
		Model::PostDraw();

		dxCommon->PostDraw();
	}

	// 释放
	delete model;
	model = nullptr;

	// 引擎结束
	Finalize();

	return 0;
}
```
