# Model

模型就是 = **3D本体 + 2D贴图**  
处理模型时,一般有以下步骤
```text
读取贴图并创建句柄存编号（textureHandle）
↓
把编号交给 Model 指针对象(到此处和读图片一致)
↓
Model 还需要 WorldTransform 与 Camera
↓
之后通过 Model 指针操作3D模型
```

素材放置 : `DirectXGame/Resources`

## 1. 读取贴图并存进句柄

创建句柄，使用 `Load()` 读取贴图，并把得到的贴图编号存进句柄。

```cpp
uint32_t textureHandle = 0;
textureHandle = TextureManager::Load("mario.jpg");
```

- `textureHandle`
  : 保存读取贴图后得到的图片编号（Handle）

- `TextureManager::Load()`
  : 读取图片并返回对应编号

---

## 2. 生成 Model 实例

创建 Model 指针，再用 `Create()` 生成 Model 对象。

```cpp
Model* model = nullptr;
model = Model::Create();
```

- `Model* model`
  : Model 类型的指针变量，用于之后操作生成出来的 3D Model 对象；
  
  和 Sprite 实例创建时就指定贴图不同，Model 实例创建时通常不直接指定贴图，因为贴图一般在 `Draw()` 时再交给 Model 使用

- `nullptr`
  : 表示目前还没有指向任何对象

- `Model::Create()`
  : 属于 `Model` 的生成函数，用于创建 3D Model 对象

---

## 3. WorldTransform 与 Camera 的初始化

`WorldTransform` 与 `Camera` 是包含在 KAMATA ENGINE 里的类。  
因为已经包含在 `KamataEngine.h` 中，所以可以不单独 `include` 直接使用。

它们内部包含 模型坐标,旋转缩放和摄像机视角等相关功能参数与函数。  
因此需要事先创建他们的实例并初始化，之后才能在绘制模型时将其作为参数使用。

```cpp
WorldTransform worldTransform;
Camera camera;

worldTransform.Initialize();
camera.Initialize();
```

---

## 4. 绘图

和 `Sprite` 与 `DirectXCommon` 一样，  
`Model` 也有自己的 `PreDraw()` 与 `PostDraw()`。

- `dxCommon`
  : 控制整个画面的绘图开始与结束, 位于所有绘图处理的最外层

- `Sprite`
  : 控制 Sprite 图片系统自己的绘图开始与结束

- `Model`
  : 控制 3D Model 系统自己的绘图开始与结束

```cpp
dxCommon->PreDraw();

Model::PreDraw();

model->Draw(worldTransform, camera, textureHandle);

Model::PostDraw();

dxCommon->PostDraw();
```

---

## 5. 释放

```cpp
delete model;
model = nullptr;
```

## 完整演示代码

```cpp
#include <Windows.h>
#include "KamataEngine.h"

using namespace KamataEngine;

int WINAPI WinMain(_In_ HINSTANCE, _In_opt_ HINSTANCE, _In_ LPSTR, _In_ int) {

	// 初期化区
	Initialize(L"GC2C_02_ゴ_チュウ");

	DirectXCommon* dxCommon = DirectXCommon::GetInstance();

	// 读取贴图并创建句柄
	uint32_t textureHandle = 0;
	textureHandle = TextureManager::Load("mario.jpg");

	// 创建 Model 实例
	Model* model = nullptr;
	model = Model::Create();

	// WorldTransform 与 Camera 的实例创建, 初始化
	WorldTransform worldTransform;
	worldTransform.Initialize();
	Camera camera;
	camera.Initialize();

	// 主循环
	while (true) {

		if (Update()) {
			break;
		}

		// 更新处理: 模型旋转
		worldTransform.rotation_.y += 0.02f;

		// DirectX 绘图开始
		dxCommon->PreDraw();

		// Model 绘图开始
		Model::PreDraw();

		// Model 绘图
		model->Draw(worldTransform, camera, textureHandle);

		// Model 绘图结束
		Model::PostDraw();

		// DirectX 绘图结束
		dxCommon->PostDraw();
	}

	// 释放
	delete model;
	model = nullptr;

	// 引擎结束
	Finalize();

	return 0;
}
```
