# 音频与键盘输入

```text
使用 Load 函数读取音源句柄
↓
使用 Play 函数播放音源句柄，并返回一个声音句柄（voiceHandle）用于保存正在播放的声音编号
↓
使用声音句柄循环和停止音乐
```

### 和 Sprite / Model 不同，音频操作不需要 `Create()` 实例，`PlayWave()`、`StopWave()` 可以直接使用句柄操作

素材放置 : `DirectXGame/Resources`

音频目前只支持：`.wav`

## 1. 使用 LoadWave() 读取音频

使用 `LoadWave()` 读取音频，并把得到的音频编号存进句柄。

```cpp
uint32_t soundDataHandle = 0;
soundDataHandle = Audio::GetInstance()->LoadWave("se_sad03.wav");
```

- `soundDataHandle`
  : 用于保存音频句柄

- `Audio::GetInstance()`
  : 用于取得 Audio 系统，并调用 `LoadWave()`

- `LoadWave()`
  : 读取音频并返回句柄

---

## 2. 使用 PlayWave() 播放音频

使用 `PlayWave()` 播放句柄对应的音源。

```cpp
Audio::GetInstance()->PlayWave(soundDataHandle, false);
```

- `false`
  : 控制是否循环播放，`false` 表示不循环

---

## 3. 使用 StopWave() 停止播放

`StopWave()` 无法直接使用音源句柄停止音乐，  
需要使用 `voiceHandle` 保存 `PlayWave()` 的返回值。

`voiceHandle` 代表当前正在播放的声音编号，  
之后可以用这个编号停止音乐。

```cpp
uint32_t voiceHandle = 0;
voiceHandle = Audio::GetInstance()->PlayWave(soundDataHandle, true);

Audio::GetInstance()->StopWave(voiceHandle);
```

- `voiceHandle`
  : 保存当前播放中的声音编号

- `true`
  : 控制是否循环播放，`true` 表示循环播放

---

## 4. 关于键盘输入

KAMATA ENGINE 的键盘输入由 `Input` 管理。

```cpp
Input::GetInstance()->TriggerKey(DIK_SPACE)
```

- `Input::GetInstance()`
  : 用于取得 Input 输入系统

- `TriggerKey()`
  : 检测按键按下瞬间

- `DIK_SPACE`
  : 空格键

---

## 完整演示代码

```cpp
#include <Windows.h>
#include "KamataEngine.h"

using namespace KamataEngine;

int WINAPI WinMain(
	_In_ HINSTANCE,
	_In_opt_ HINSTANCE,
	_In_ LPSTR,
	_In_ int) {

	// 初期化区
	Initialize(L"GC2C_02_ゴ_チュウ");

	DirectXCommon* dxCommon =
		DirectXCommon::GetInstance();

	// 读取音频并创建句柄
	uint32_t soundDataHandle = 0;

	soundDataHandle =
		Audio::GetInstance()->LoadWave(
			"se_sad03.wav");

	// 保存循环播放中的声音编号
	uint32_t voiceHandle = 0;

	voiceHandle =
		Audio::GetInstance()->PlayWave(
			soundDataHandle,
			true);

	// 主循环
	while (true) {

		if (Update()) {
			break;
		}

		// 按下空格键瞬间停止音频
		if (Input::GetInstance()->TriggerKey(DIK_SPACE)) {

			Audio::GetInstance()->StopWave(
				voiceHandle);
		}

		dxCommon->PreDraw();
		dxCommon->PostDraw();
	}

	// 引擎结束
	Finalize();

	return 0;
}
```
