# 音频与键盘输入

```text
读取音频并创建句柄存编号（soundDataHandle）
↓
使用 Audio 播放音频
↓
循环播放时需要保存 voiceHandle
↓
通过 Input 检测键盘输入
↓
根据按键控制音频停止等处理
```

素材放置 : `DirectXGame/Resources`

音频目前只支持：

- `.wav`

## 1. 读取音频并存进句柄

创建句柄，使用 `LoadWave()` 读取音频，并把得到的音频编号存进句柄。

```cpp
uint32_t soundDataHandle = 0;

soundDataHandle =
    Audio::GetInstance()->LoadWave("se_sad03.wav");
```

- `soundDataHandle`
  : 保存读取音频后得到的音频编号（Handle）

- `Audio::GetInstance()`
  : 获取引擎内部已经存在的 Audio 管理对象

- `LoadWave()`
  : 读取 `.wav` 音频并返回对应编号

---

## 2. 播放音频

使用 `PlayWave()` 播放已经读取完成的音频。

```cpp
Audio::GetInstance()->PlayWave(soundDataHandle);
```

- `PlayWave()`
  : 播放指定音频

- `soundDataHandle`
  : 指定要播放哪一个音频

---

## 3. 循环播放与停止

循环播放时，需要保存返回的播放编号（voiceHandle）。

之后停止音频时，需要指定这个编号。

```cpp
uint32_t voiceHandle = 0;

voiceHandle =
    Audio::GetInstance()->PlayWave(
        soundDataHandle, true);
```

- `voiceHandle`
  : 保存当前播放中的音频编号

- `true`
  : 表示循环播放（Loop）

停止音频：

```cpp
Audio::GetInstance()->StopWave(voiceHandle);
```

---

## 4. 键盘输入

KAMATA ENGINE 的键盘输入由 `Input` 管理。

```cpp
Input::GetInstance()->TriggerKey(DIK_SPACE)
```

- `Input::GetInstance()`
  : 获取 Input 输入管理对象

- `TriggerKey()`
  : 检测按键按下瞬间

- `DIK_SPACE`
  : 空格键

常见按键：

```cpp
DIK_W
DIK_A
DIK_S
DIK_D
DIK_SPACE
DIK_ESCAPE
```

## 完整演示代码

```cpp
#include <Windows.h>
#include "KamataEngine.h"

using namespace KamataEngine;

int WINAPI WinMain(
	_In_ HINSTANCE,
	_In_opt_ HINSTANCE,
	_In_ LPSTR,
	_In_ int) {

	// 初期化区
	Initialize(L"GC2C_02_ゴ_チュウ");

	DirectXCommon* dxCommon =
		DirectXCommon::GetInstance();

	// 读取音频并创建句柄
	uint32_t soundDataHandle = 0;

	soundDataHandle =
		Audio::GetInstance()->LoadWave(
			"se_sad03.wav");

	// 保存循环播放中的音频编号
	uint32_t voiceHandle = 0;

	voiceHandle =
		Audio::GetInstance()->PlayWave(
			soundDataHandle,
			true);

	// 主循环
	while (true) {

		if (Update()) {
			break;
		}

		// 按下空格键瞬间停止音频
		if (Input::GetInstance()->TriggerKey(DIK_SPACE)) {

			Audio::GetInstance()->StopWave(
				voiceHandle);
		}

		// DirectX 绘图开始
		dxCommon->PreDraw();

		// DirectX 绘图结束
		dxCommon->PostDraw();
	}

	// 引擎结束
	Finalize();

	return 0;
}
```
