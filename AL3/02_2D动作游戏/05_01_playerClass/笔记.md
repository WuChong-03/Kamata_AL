# 05_01_PlayerClass

04 阶段主要是在 `GameScene` 或 `main` 中直接测试引擎功能，  
而 05 阶段要把玩家的

- 位置
- 模型
- 贴图
- 更新处理
- 绘制处理

等都分离到 `Player` 类中。  
`GameScene` 只负责创建和调用 `Player`。

---

## 1. 玩家类基础结构，并在 Scene 中创建实例

### `Player.h`

```cpp
#pragma once

#include "KamataEngine.h"

using namespace KamataEngine;

class Player {
public:
	void Initialize();
	void Update();
	void Draw();

private:
	// 世界变换数据
	WorldTransform worldTransform_;

	// 模型
	Model* model_ = nullptr;

	// 贴图句柄
	uint32_t textureHandle_ = 0u;

	// 摄像机
	Camera* camera_ = nullptr;
};
```

### `Player.cpp`

```cpp
#include "Player.h"

void Player::Initialize() {}

void Player::Update() {}

void Player::Draw() {}
```

### `GameScene.h`

```cpp
#include "Player.h"

using namespace KamataEngine;

private:
	Player* player_ = nullptr;
```

### `GameScene.cpp`

#### `GameScene::Initialize`

```cpp
player_ = new Player();
player_->Initialize();
```

#### `GameScene::Update`

```cpp
player_->Update();
```

#### `GameScene::Draw`

```cpp
player_->Draw();
```

#### `GameScene::~GameScene`

```cpp
delete player_;
player_ = nullptr;
```

`GameScene` 中创建的 `player` 实例，其释放也与 `GameScene` 绑定。

同样，`main` 中创建的 `scene` 实例，其释放由 `main` 负责。

## 2. 扩展 Player 的 Initialize、Update、Draw

`Player` 类作为一个通用模板，可以用于多个项目，所以不在里面固定写死资源。  
我们把资源放在 `Scene` 中，通过 `Player` 的初始化函数导入资源并使用即可。

这里主要传入三个东西：

- 模型 model
- 贴图 texture
- 摄像机 camera

### `Player.h`

```cpp
void Initialize(
	Model* model,
	uint32_t textureHandle,
	Camera* camera
);
```

### `Player.cpp`

```cpp
#include "Player.h"
#include <cassert>

using namespace KamataEngine;

void Player::Initialize(
	Model* model,
	uint32_t textureHandle,
	Camera* camera
) {
	// 1. 检查模型是否为空指针
	assert(model);

	// 2. 把参数保存到 Player 的成员变量中
	model_ = model;
	textureHandle_ = textureHandle;
	camera_ = camera;

	// 3. 世界变换初始化
	worldTransform_.Initialize();
}

void Player::Update() {
	// 更新世界变换
	worldTransform_.TransferMatrix();
}

void Player::Draw() {
	// 绘制模型
	model_->Draw(
		worldTransform_,
		*camera_,
		textureHandle_
	);
}
```

## 3. Scene 中传入参数

### `GameScene.h`

```cpp
#pragma once

#include "KamataEngine.h"
#include "Player.h"

using namespace KamataEngine;

class GameScene {
public:
	void Initialize();
	void Update();
	void Draw();
	~GameScene();

private:
	// 贴图句柄
	uint32_t modelTextureHandle_ = 0u;

	// 模型
	Model* model_ = nullptr;

	// 摄像机
	Camera* camera_ = nullptr;

	// 玩家
	Player* player_ = nullptr;
};
```

### `GameScene.cpp`

#### `GameScene::Initialize`

```cpp
void GameScene::Initialize() {

	// player 贴图
	modelTextureHandle_ = TextureManager::Load("test/image.png");

	// 创建模型
	model_ = Model::Create();

	// 创建摄像机并初始化
	camera_ = new Camera();
	camera_->Initialize();

	// 创建 Player 实例并初始化
	player_ = new Player();
	player_->Initialize(model_, modelTextureHandle_, camera_);
}
```

#### `GameScene::Update`

```cpp
void GameScene::Update() {
	player_->Update();
}
```

#### `GameScene::Draw`

```cpp
void GameScene::Draw() {

	// Model 绘图开始
	Model::PreDraw();

	// Player 绘制
	player_->Draw();

	// Model 绘图结束
	Model::PostDraw();
}
```

#### `GameScene::~GameScene`

```cpp
GameScene::~GameScene() {

	delete player_;
	player_ = nullptr;

	delete model_;
	model_ = nullptr;

	delete camera_;
	camera_ = nullptr;
}
```

`Model::PreDraw()` 和 `Model::PostDraw()` 已经放到 `GameScene::Draw()` 里了。

```cpp
dxCommon->PreDraw();

```

## 5. 关于释放

`GameScene` 中创建的 `player` 实例，其释放也与 `GameScene` 绑定。

`GameScene` 中通过 `Model::Create()` 创建的 `model_`，也由 `GameScene` 释放。

`GameScene` 中通过 `new Camera()` 创建的 `camera_`，也由 `GameScene` 释放。

简单记法：

自己创建的，自己释放。  
只是接收来用的，不随便释放。
