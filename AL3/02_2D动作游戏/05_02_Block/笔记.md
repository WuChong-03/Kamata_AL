# 05_02_Block

## 0. 本节目标

05_02 主要是在 `GameScene` 中生成多个方块模型，并用 `std::vector` 管理多个 `WorldTransform`。

本节重点：

- 在 `GameScene` 中生成方块模型
- 使用 `std::vector` 保存多个方块的 `WorldTransform`
- 用 `for` 循环批量初始化、更新、绘制、释放
- 使用二维 `std::vector` 实现纵横排列
- 允许中间有空洞，也就是某些位置没有方块
- 追加 DebugCamera，方便开发时观察场景

---

## 1. 模型数据生成

这次要生成的是方块模型，和自机模型不同。  
所以需要在 `GameScene` 中另外准备方块用的模型数据。

### `GameScene.h`

```cpp
// 3D模型数据
Model* modelBlock_ = nullptr;
```

### `GameScene.cpp`

#### `GameScene::Initialize`

```cpp
// 3D模型数据の生成
modelBlock_ = Model::Create();
```

#### `GameScene::~GameScene`

```cpp
delete modelBlock_;
modelBlock_ = nullptr;
```

`modelBlock_` 是方块用模型。  
因为它是通过 `Model::Create()` 创建的，所以要在析构函数中 `delete`。

---

## 2. 使用 std::vector

因为方块数量可能会变，所以这次不用普通数组，而是用 `std::vector`。

### `GameScene.h`

```cpp
#include <vector>
```

### 一维 vector

```cpp
std::vector<KamataEngine::WorldTransform*> worldTransformBlocks_;
```

意思是保存多个 `WorldTransform` 指针。  
每一个 `WorldTransform` 对应一个方块的位置、旋转、缩放。

普通数组也可以保存多个元素，但 `std::vector` 可以根据需要改变数量，更适合关卡、地图、方块这种数量可能变化的数据。

---

## 3. 一维方块初始化

### `GameScene.cpp`

#### `GameScene::Initialize`

```cpp
// 要素数
const uint32_t kNumBlockHorizontal = 20;

// ブロック1個分の横幅
const float kBlockWidth = 2.0f;

// 要素数を変更する
worldTransformBlocks_.resize(kNumBlockHorizontal);

// キューブの生成
for (uint32_t i = 0; i < kNumBlockHorizontal; ++i) {

	worldTransformBlocks_[i] = new WorldTransform();
	worldTransformBlocks_[i]->Initialize();
	worldTransformBlocks_[i]->translation_.x = kBlockWidth * i;
	worldTransformBlocks_[i]->translation_.y = 0.0f;
}
```

流程：

1. 决定横向方块数量
2. 决定每个方块之间的距离
3. 用 `resize()` 改变 `vector` 的元素数量
4. 用 `for` 循环一个一个生成 `WorldTransform`
5. 设置每个方块的位置

`i` 是横向编号。  
`kBlockWidth * i` 可以让每个方块在 x 方向依次错开。

---

## 4. 一维方块更新

### `GameScene.cpp`

#### `GameScene::Update`

```cpp
// ブロックの更新
for (WorldTransform* worldTransformBlock : worldTransformBlocks_) {

	// 定数バッファに転送する
	worldTransformBlock->TransferMatrix();
}
```

这里使用范围 `for` 循环，把 `worldTransformBlocks_` 里的元素一个一个取出来处理。

`TransferMatrix()` 的作用是把位置、旋转、缩放的变化更新到绘制用数据里。  
不调用的话，数据改了但画面可能不会正确反映。

---

## 5. 一维方块绘制

### `GameScene.cpp`

#### `GameScene::Draw`

```cpp
// ブロックの描画
for (WorldTransform* worldTransformBlock : worldTransformBlocks_) {
	modelBlock_->Draw(*worldTransformBlock, camera_);
}
```

这里也是用范围 `for` 循环，把每一个方块都绘制出来。

注意：

```cpp
*worldTransformBlock
```

因为 `worldTransformBlock` 是指针。  
`Draw()` 需要的是 `WorldTransform` 本体，所以要加 `*` 解引用。

---

## 6. 一维方块释放

### `GameScene.cpp`

#### `GameScene::~GameScene`

```cpp
for (WorldTransform* worldTransformBlock : worldTransformBlocks_) {
	delete worldTransformBlock;
}

worldTransformBlocks_.clear();
```

因为每个方块的 `WorldTransform` 都是这样生成的：

```cpp
worldTransformBlocks_[i] = new WorldTransform();
```

所以最后必须一个一个 `delete`。

`clear()` 的作用是清空 `vector` 里的元素。  
但注意：`clear()` 只是清空容器，不会自动 `delete` 指针指向的对象。  
所以必须先 `delete`，再 `clear()`。

---

## 7. 二维 std::vector

一维只能横向排一排。  
如果要做成纵横排列，就需要二维结构。

### `GameScene.h`

```cpp
std::vector<std::vector<KamataEngine::WorldTransform*>> worldTransformBlocks_;
```

这个类型可以理解成：

```md
外层 vector：保存每一行
内层 vector：保存这一行里的每一个方块
```

也就是：

```cpp
worldTransformBlocks_[纵向编号][横向编号]
```

通常：

```cpp
i = 纵方向编号
j = 横方向编号
```

---

## 8. 二维方块初始化：先 resize

### `GameScene.cpp`

#### `GameScene::Initialize`

```cpp
// 要素数
const uint32_t kNumBlockVertical = 10;
const uint32_t kNumBlockHorizontal = 20;

// ブロック1個分の横幅
const float kBlockWidth = 2.0f;
const float kBlockHeight = 2.0f;

// 要素数を変更する
// 列数を設定（縦方向のブロック数）
worldTransformBlocks_.resize(kNumBlockVertical);

for (uint32_t i = 0; i < kNumBlockVertical; ++i) {

	// 1列の要素数を設定（横方向のブロック数）
	worldTransformBlocks_[i].resize(kNumBlockHorizontal);
}
```

二维 `vector` 要先设置外层数量，再设置每一行里面的数量。

简单理解：

```md
先决定有几行
再决定每一行有几个
```

---

## 9. 二维方块初始化：生成方块

### `GameScene.cpp`

#### `GameScene::Initialize`

```cpp
// ブロックの生成
for (uint32_t i = 0; i < kNumBlockVertical; ++i) {

	for (uint32_t j = 0; j < kNumBlockHorizontal; ++j) {

		worldTransformBlocks_[i][j] = new WorldTransform();
		worldTransformBlocks_[i][j]->Initialize();

		worldTransformBlocks_[i][j]->translation_.x = kBlockWidth * j;
		worldTransformBlocks_[i][j]->translation_.y = kBlockHeight * i;
	}
}
```

这里用二重 `for` 循环生成方块。

```md
i 控制纵方向
j 控制横方向
```

位置设置：

```cpp
translation_.x = kBlockWidth * j;
translation_.y = kBlockHeight * i;
```

意思是：

```md
j 越大，方块越往右
i 越大，方块越往上或往下
```

---

## 10. 二维方块释放

### `GameScene.cpp`

#### `GameScene::~GameScene`

```cpp
for (std::vector<WorldTransform*>& worldTransformBlockLine : worldTransformBlocks_) {

	for (WorldTransform* worldTransformBlock : worldTransformBlockLine) {

		delete worldTransformBlock;
	}
}

worldTransformBlocks_.clear();
```

二维 `vector` 需要二重 `for` 释放。

外层：

```cpp
for (std::vector<WorldTransform*>& worldTransformBlockLine : worldTransformBlocks_)
```

意思是从二维 `vector` 中一行一行取出来。

内层：

```cpp
for (WorldTransform* worldTransformBlock : worldTransformBlockLine)
```

意思是从这一行中一个一个取出方块指针并 `delete`。

这里的 `&` 很重要。  
加 `&` 表示引用原本的数据，不复制一份。

---

## 11. 二维方块更新

### `GameScene.cpp`

#### `GameScene::Update`

```cpp
for (std::vector<WorldTransform*>& worldTransformBlockLine : worldTransformBlocks_) {

	for (WorldTransform* worldTransformBlock : worldTransformBlockLine) {

		worldTransformBlock->TransferMatrix();
	}
}
```

二维结构更新时，也需要二重 `for`。

流程：

```md
先取出一行
再取出这一行里的每个方块
然后调用 TransferMatrix()
```

## 12. 二维方块绘制

### `GameScene.cpp`

#### `GameScene::Draw`

```cpp
for (std::vector<WorldTransform*>& worldTransformBlockLine : worldTransformBlocks_) {

	for (WorldTransform* worldTransformBlock : worldTransformBlockLine) {

		modelBlock_->Draw(*worldTransformBlock, camera_);
	}
}
```

绘制也是同样的结构：

```md
外层 for：遍历每一行
内层 for：遍历每一行里的每个方块
```

每个方块都用同一个 `modelBlock_` 绘制，但使用不同的 `WorldTransform`，所以会显示在不同位置。

## 13. 允许空洞

如果希望地图中有些位置没有方块，可以让某些元素保持 `nullptr`。

也就是说：

```md
有方块的位置：保存 WorldTransform 指针
没有方块的位置：保存 nullptr
```

这样就可以做出中间有空洞的地图。

---

## 14. 空指针检查：Update

### `GameScene.cpp`

#### `GameScene::Update`

```cpp
for (std::vector<WorldTransform*>& worldTransformBlockLine : worldTransformBlocks_) {

	for (WorldTransform* worldTransformBlock : worldTransformBlockLine) {

		if (!worldTransformBlock) {
			continue;
		}

		worldTransformBlock->TransferMatrix();
	}
}
```

如果某个位置是 `nullptr`，说明那里没有方块。  
这时不能调用：

```cpp
worldTransformBlock->TransferMatrix();
```

否则会崩溃。

所以先检查：

```cpp
if (!worldTransformBlock) {
	continue;
}
```

意思是：

```md
如果这个位置没有方块，就跳过本次循环。
```

这种写法叫做“保护处理”或“空指针检查”。

---

## 15. 空指针检查：Draw

### `GameScene.cpp`

#### `GameScene::Draw`

```cpp
for (std::vector<WorldTransform*>& worldTransformBlockLine : worldTransformBlocks_) {

	for (WorldTransform* worldTransformBlock : worldTransformBlockLine) {

		if (!worldTransformBlock) {
			continue;
		}

		modelBlock_->Draw(*worldTransformBlock, camera_);
	}
}
```

绘制时也一样。  
如果某个位置是 `nullptr`，说明那里没有方块，就跳过绘制。

否则这里会出问题：

```cpp
*worldTransformBlock
```

因为空指针不能解引用。

---

## 16. 空洞地图的思路

如果要做出有洞的地图，可以在生成方块时判断某些位置不生成。

例子：

```cpp
if ((i + j) % 2 == 0) {
	continue;
}
```

或者：

```cpp
if (j % 2 == 1) {
	continue;
}
```

这些位置不 `new WorldTransform()`，就会保持 `nullptr`。  
之后 `Update` 和 `Draw` 里通过空指针检查跳过这些位置。

简单理解：

```md
nullptr = 这里没有方块
非 nullptr = 这里有方块
```

### `GameScene.cpp`


这样鼠标、键盘操作才能影响摄像机视角。

## 20. #ifdef _DEBUG

DebugCamera 是开发调试用功能。  
正式发布时一般不需要。

可以用：

```cpp
#ifdef _DEBUG

// 只在 Debug 模式下执行的代码

#endif
```

`#ifdef _DEBUG` 和 `#endif` 之间的代码，只会在 Debug 构建时有效。  
Release 构建时，这部分代码相当于不存在。

### `GameScene.cpp`

#### `GameScene::Update`

```cpp
#ifdef _DEBUG

if (Input::GetInstance()->TriggerKey(切り替えキー)) {

	// デバッグカメラ有効フラグをトグル
	isDebugCameraActive_ = !isDebugCameraActive_;
}

#endif
```

`TriggerKey()` 用来检测“按下的一瞬间”。  
这里按下切换键时，把 `isDebugCameraActive_` 在 `true / false` 之间切换。

```md
false → true
true → false
```

这种开关切换叫做 toggle。

---

## 21. DebugCamera 的处理

DebugCamera 启用时，需要把 DebugCamera 的矩阵复制到普通 camera 里。

### `GameScene.cpp`

#### `GameScene::Update`

```cpp
// カメラの処理
if (isDebugCameraActive_) {

	// デバッグカメラの更新
	debugCamera_->Update();

	// デバッグカメラのビュー行列をコピー
	camera_.matView = debugCamera_->GetCamera().matView;

	// デバッグカメラのプロジェクション行列をコピー
	camera_.matProjection = debugCamera_->GetCamera().matProjection;

	// ビュープロジェクション行列の転送
	camera_.TransferMatrix();

} else {

	// ビュープロジェクション行列の更新と転送
	camera_.UpdateMatrix();
}
```

简单理解：

```md
DebugCamera 开启：
使用 DebugCamera 的视角

DebugCamera 关闭：
使用普通 Camera 的视角
```

因为实际绘制时还是使用 `camera_`，所以开启 DebugCamera 时，要把 DebugCamera 的视图矩阵和投影矩阵复制到 `camera_` 中。

这样 `Draw()` 里不用改，还是照常使用 `camera_`。

---

## 22. DebugCamera 的运行结果

按下切换键后，DebugCamera 会启用。  
启用后可以从不同角度观察场景，方便检查方块的位置、排列和空洞。

简单来说：

```md
普通 Camera：游戏实际使用的视角
DebugCamera：开发时自由查看场景的视角
```

DebugCamera 主要用于开发调试，正式游戏里一般不让玩家看到。

## 23. 当前整体结构

到这里为止，`GameScene` 大概会管理这些内容：

```cpp
Model* modelBlock_ = nullptr;

std::vector<std::vector<WorldTransform*>> worldTransformBlocks_;

bool isDebugCameraActive_ = false;

DebugCamera* debugCamera_ = nullptr;
```

主要流程：

```md
Initialize：
生成模型
生成 WorldTransform
生成 DebugCamera

Update：
更新 WorldTransform
按键切换 DebugCamera
更新 Camera

Draw：
绘制方块

Destructor：
delete 模型
delete WorldTransform
delete DebugCamera
clear vector
```

简单记法：

```md
多个方块 = 多个 WorldTransform
多个 WorldTransform = 用 vector 管理
二维地图 = vector 的 vector
空洞 = nullptr
new 出来的 = 析构里 delete
DebugCamera = 开发用自由视角
```
